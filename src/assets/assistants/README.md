# Assistant portrait assets

Add the five launch portraits to this directory as `assistant_01.png` through
`assistant_05.png`. Future files (`assistant_06.png` through `assistant_10.png`)
must not be referenced in `src/config/assistantAvatars.ts` until they exist.

Portraits are square PNGs and are rendered with `resizeMode="cover"`. This
repository intentionally does not include or generate avatar artwork.
